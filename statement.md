# Job Application Tracker

## 1. Problem Statement

Students and people looking for jobs usually apply for a number of different jobs and internships at the same time, which makes it difficult to keep account of all the details concerning each application.

Each application can include details like the company name, the job position, the location, the date of the application, the deadline, the salary or stipend, the source from which the application was made, and the present status. It is likewise easy to forget an interview, an online test, or a follow-up appointment.

Filling notes, spreadsheets, or various files with all this information can be both time-consuming and confusing, and it is easy to overlook the important details.

The Job Application Tracker is intended to deal with this issue by having all the details of job and internship applications stored in a single location. Whenever necessary, users may add, view, search, filter, update, sort, and delete the applications.

The programme also assists users in keeping record of deadlines, follow-up dates, priorities, and the status of their applications; it includes some basic statistics which allow users to obtain an idea of how their applications are progressing.

It is a console application based on Java which saves its data to a text file and can be executed from the command line without the need for a database or any other external software.

## 2. The Extent of the Project

This project is mainly intended to make it easier for students and job hunters to handle their job and internship applications from a single location.

The project allows users to:

* Include applications for jobs and internships.
* Record details for each application.
* See what the status of the application is.
* Search for applications by either entering the company name or the job position.
* Sort the applications by their status or type.
* Change the status of an application.
* Remove applications that are no longer needed.
* Order the applications by company, date, or priority.
* Add follow-up dates.
* Look at the follow-ups that are due soon and those that are overdue.
* View application statistics.
* Save the app data in a text file.
* When the program is started, load the data that has previously been saved.
* Export application details into a report.

This version is intended to be used via the command line and has no features like direct job searching, applying for jobs, user accounts, cloud storage, or the ability to communicate with companies.

The project could be improved in the future by including a graphical interface, adding database support, providing notifications, offering cloud storage, and integrating with job portals.

## 3. Target Users

This project is mainly used by students, recent graduates, and those who are currently seeking jobs.

### Students

Students who are applying for internships, placements or part-time jobs may use the Job Application Tracker to keep their applications in order and to check on their progress.

### Recent Graduates

Fresh graduates who are applying for their first jobs can make use of the tracker to maintain a record of the companies, the deadlines, the interviews, and the various stages of the recruitment process.

### Job Seekers

Individuals who are currently looking for work can use the application to keep a record of the jobs they have applied for and to monitor the status of their applications.

Basically, the Job Application Tracker is built so that anyone can have a simple method of managing their job and internship applications all in one place.

## 4. High-Level Features

### 4.1 Add Application

A user may add a job or internship application by filling in information like the company name, the position, the location, the application date, the type, the status, the salary or stipend, the application source, the deadline, the follow-up date, the priority, and the notes.

### 4.2 View Applications

Users have the ability to see all the applications that they have saved together with their details.

### 4.3 Search Applications

An application can be searched for by means of either the company name or the job position. This in turn makes it easier to find an application without having to go through the entire list.

### 4.4 Filter Applications

Applications can be filtered according to their status or type; for instance, a user might select to see only those relating to internships or those which are currently at the interview stage.

### 4.5 Update Application Status

Users have the possibility of altering the status of their application should there be any changes to the recruitment process.

The available statuses are:

* Applied
* Shortlisted
* Online Test
* Interview
* Selected
* Rejected

### 4.6 Delete Application

Users have the option of deleting an application when they no longer need to retain its record.

### 4.7 Application Statistics

The Job Application Tracker includes basic statistics, for example the total number of applications and the number of applications according to different statuses.

### 4.8 Follow-Up Tracking

Users have the option of assigning follow-up dates to their applications and can then see which applications have follow-ups that are due or that are overdue.

### 4.9 Sort Applications

Users have the option of sorting their applications by company name, application date, or priority; this helps them to arrange the list in accordance with their own needs.

### 4.10 File Storage

The details of the application are stored in a text file, which ensures that the data is still available after the program has been closed and then reopened.

### 4.11 Export Report

Users have the option of exporting their application details into a report file, thus obtaining a separate copy of their application records which they can refer to later on.

## 5. Project Overview

The Job Application Tracker is a console application written in Java which is designed to help people keep their job and internship applications in a simple and organized manner.

The project makes use of various Java features such as classes and objects, ArrayList, file handling, polymorphism, exception handling, date and time, Scanner, and Comparator.

Classes are employed to deal with various parts of the application, for example those concerned with storing the application details, managing the applications, saving and loading files, calculating statistics, and looking after dates.

The project's primary aim is to ensure that job application tracking is simple, well-organized, and easy to use when carried out via the command line.
